## Troubleshooting Guide

### Common Issues and Solutions

#### Issue: Widget not appearing
**Solution**: 
1. Check context processor is registered in settings.py
2. Verify user role is DPM, VIDEO_PM, or SENIOR_MANAGER
3. Check template syntax in base.html

#### Issue: Timers not updating
**Solution**:
1. Check JavaScript console for errors
2. Verify AJAX endpoint is accessible
3. Check network tab for 403/404 errors
4. Ensure URL pattern is correct

#### Issue: Dropdown not opening
**Solution**:
1. Verify Bootstrap JavaScript is loaded
2. Check for JavaScript errors
3. Ensure data-bs-toggle attribute is present

#### Issue: Poor performance
**Solution**:
1. Check number of database queries in Django Debug Toolbar
2. Verify select_related and prefetch_related are working
3. Consider implementing caching

#### Issue: Timer shows wrong time
**Solution**:
1. Check timezone settings in Django
2. Verify JavaScript date parsing
3. Ensure started_at timestamp is in correct format
